# Privacy Policy

**Application:** Booking System
**Last Updated:** March 2026

## Note

The application did not provide a privacy policy at `/privacypolicy`.
This document proposes a privacy policy to improve transparency and support GDPR compliance.

---

# 1. Introduction

This Privacy Policy explains how the **Booking System** collects, uses, stores, and protects user information when users access or use the application.

The application allows users to **add and reserve resources** through a user account.

By using the application, users agree to the collection and use of information in accordance with this policy.

---

# 2. Information We Collect

When users register and use the application, the following personal data may be collected:

* Email address
* Password (stored securely in hashed form)
* Birthdate
* User role

Additionally, the system may collect:

* Session data used to maintain user authentication
* Basic usage information necessary for system functionality

---

# 3. Purpose of Data Collection

The collected data is used for the following purposes:

* Creating and managing user accounts
* Authenticating users during login
* Allowing users to reserve and manage resources
* Maintaining system functionality and security

The application does not use personal data for advertising or marketing purposes.

---

# 4. Data Storage and Security

User information is stored in a **PostgreSQL database**.
Reasonable technical and organizational measures are implemented to protect data from:

* Unauthorized access
* Alteration
* Disclosure
* Destruction

Passwords are stored in a **secure hashed format** and are not stored as plain text.

---

# 5. Cookies and Sessions

The application uses **cookies or session mechanisms** to:

* Maintain user login sessions
* Authenticate users during system usage
* Ensure secure access to protected areas of the application

These cookies are essential for the operation of the application.

---

# 6. Third-Party Services

The Booking System **does not use third-party services** for analytics, authentication, or payment processing.

All data processing occurs within the application’s own system.

---

# 7. User Rights

Users have the right to:

* Access their personal data stored in the system
* Request correction of inaccurate information

Currently, the system **does not provide a built-in mechanism for account deletion**.

---

# 8. Data Retention

User data is stored for as long as the user account exists in the system or as long as necessary to maintain the functionality of the application.

---

# 9. Contact Information

If users have questions regarding this Privacy Policy or the handling of personal data, they may contact the system administrator using the email address associated with their account.

---

# 10. Changes to This Privacy Policy

This Privacy Policy may be updated in the future to reflect changes in the application, legal requirements, or data processing practices.

Users are encouraged to review this policy periodically.
