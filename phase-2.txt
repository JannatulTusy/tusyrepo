Theoretical Questions

1. Difference between Dictionary and Non-Dictionary Attacks

A dictionary attack uses a predefined list of common passwords to test against hashes. It is efficient because it targets passwords that users are likely to choose.

A non-dictionary attack, such as brute-force, tries all possible combinations of characters systematically. It does not rely on known password lists but requires significantly more computational power and time.

2. What advantage does an attacker gain if a database with password hashes is leaked?

If a database of password hashes is leaked, the attacker can perform offline cracking without interacting with the target system. There are no login limits or rate restrictions, allowing billions of guesses per second. If passwords are weak or reused across services, attackers may gain access to multiple accounts. Administrative accounts become especially valuable targets.

3. Why longer passwords improve security?

Longer passwords increase the total keyspace exponentially, making brute-force attacks significantly harder. As password length increases, the number of possible combinations grows dramatically. This increases cracking time and computational cost. Therefore, longer passwords or passphrases provide much stronger security compared to short passwords, even if the shorter ones contain special characters.
